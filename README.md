# Vanim

Aplikasi Android untuk menjelajah anime, mengikuti episode, dan melanjutkan tontonan langsung dari ponsel. Vanim memakai antarmuka **Soft Glass** dengan latar navy gelap dan aksen biru elektrik.

## Fitur

### Temukan anime
- Beranda personal: anime unggulan, lanjutkan menonton, tayang hari ini, musim berjalan, populer, dan pintasan genre.
- Jelajah dan pencarian: riwayat pencarian, filter genre/status/tipe, urutan populer atau A-Z, serta daftar berkelanjutan.
- Jadwal tayang mingguan per hari.

### Nikmati tontonan
- Pemutar fleksibel: pilih kualitas, kecepatan 0,5x-2x, mode pas atau isi layar.
- Kontrol gestur: ketuk dua kali untuk maju/mundur, geser sisi kiri untuk kecerahan dan sisi kanan untuk volume saat layar penuh.
- Lanjutkan menonton dengan progres dan posisi terakhir tersimpan.
- Episode berikutnya dengan hitung mundur otomatis.
- Picture-in-Picture.

### Koleksi dan offline
- Download offline dengan pilihan kualitas dan opsi hanya Wi-Fi.
- Riwayat tontonan dan favorit.
- Daftar episode dengan rentang halaman dan pencarian nomor episode.

### Sesuaikan pengalaman
- Tema sistem, terang, gelap, dan hitam AMOLED.
- Material 3 dengan dukungan Material You.
- Pengaturan kualitas default dan opsi pemutar.

## Build

```bash
gradle testDebugUnitTest
gradle assembleRelease
```

APK debug: `app/build/outputs/apk/debug/app-debug.apk`.
